# Features Overview

Terraforge bundles everything a QA team needs to run end-to-end automated tests in isolated environments.

## Feature Summary

| Feature                            | Description                                                                                   |
| ---------------------------------- | --------------------------------------------------------------------------------------------- |
| [Dashboard](./dashboard)           | Live metrics, quick actions, session summary                                                  |
| [Sessions](./sessions)             | Environment lifecycle management                                                              |
| [Configurations](./configurations) | Reference for available session environment templates                                         |
| [Test Runs](./test-runs)           | Browse and inspect automated test execution results                                           |
| [Monitoring](./monitoring)         | Error log aggregation and issue tracking across sessions                                      |
| [Work Items](./work-items)         | Azure DevOps work items assigned to you                                                       |
| [Run Tasks](./run-tasks)           | Execute task sequences and manage task templates and triggers                                 |

## Navigation

The left sidebar is dynamically loaded based on your role. Items not visible means you may not have the required permission level — contact your Administrator.

Use **`Ctrl+K`** (or **`⌘K`** on macOS) to open the Command Palette for fast navigation to any section.
