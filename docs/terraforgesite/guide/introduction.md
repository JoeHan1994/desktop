# What is Terraforge?

**Terraforge** is an internal test environment management and automated test execution platform. It allows QA and development teams to:

- **Provision** isolated virtual-machine based test environments (called _Sessions_)
- **Execute** automated test suites against those environments
- **Monitor** real-time progress and stream execution logs
- **Inspect** detailed results, videos, and failure evidence

## Key Capabilities

| Capability         | Description                                                   |
| ------------------ | ------------------------------------------------------------- |
| Session management | Create, checkpoint, restore, and destroy VM test environments |
| Machine access     | Connect to test VMs via browser-based Bastion terminal        |
| Test execution     | Trigger runs, track progress, view per-step logs              |
| Result browsing    | Filter by status, view logs, download artifacts               |

## Design Philosophy

Terraforge is built with the aesthetics of an **enterprise DevOps console** — minimal, professional, dark-first. Every screen is optimised for:

- High information density without visual noise
- Clear status communication (color-coded badges, progress bars)
- Keyboard-navigable interfaces and command palette access
